#🌟 Funcionalidades do Site
O site foi construído do zero (sem frameworks pesados) para garantir máxima performance:

*📱Design 100% Responsivo: Perfeito para navegar no telemóvel ou no PC.
*🤖Chatbot Inteligente: Um assistente virtual que responde automaticamente a dúvidas sobre preços, prazos e serviços.
* 💬Contacto Imediato: Formulários que preparam os dados e enviam diretamente para o meu WhatsApp privado.
*🎨 Interface Moderna:** Cores baseadas na identidade visual da marca (Azul e Dourado) e ícones SVG.
*🔒Preparado para o Futuro: Estrutura pronta para receber o sistema de login e Área do Cliente com o Firebase.

#🛠️ Tecnologias Utilizadas
Este projeto não usa "gambiarras". Foi construído com o que há de mais sólido no front-end:

*HTML5: Estrutura semântica e acessível.
*CSS3: Estilização personalizada, Flexbox, CSS Grid e animações fluidas.
*JavaScript (Vanilla): Lógica do menu, modais, barra de progresso, envio para o WhatsApp e o Chatbot.
*GitHub Pages: Hospedagem rápida, segura e gratuita.
*Firebase: Para autenticação de utilizadores e base de dados de pedidos.
